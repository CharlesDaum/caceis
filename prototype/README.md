# Evolved Prototype

Run the prototype locally from the project root:

```bash
./.venv/bin/python technical_implementation/build_evolved_prototype.py
./.venv/bin/python app.py --rebuild
```

Then open `http://127.0.0.1:8000`.

What it does:
- Predicts employees likely to exceed 30 absence days.
- Segments the workforce into interpretable personas.
- Recommends next-best actions by comparing employees to high-performing peer benchmarks.
- Simulates performance upside from review completion plus targeted training.
